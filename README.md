# RTS Minimap

Cleans the FiveM HUD down to a bare minimap — removes health bar, armor bar, wanted stars, weapon wheel, vehicle HUD, area/street names, and cash display. Leaves only the radar minimap visible behind the RTS tactical overlay.

**No dependencies.**

## Install

```
ensure rts-minimap
```

Start it before `enyo-rts` so the HUD is clean when the player connects.
